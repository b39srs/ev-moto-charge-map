W07 — Create Trip
Multi-step form + Tag selection
📋 Design Notes — Trip Detail & Create • Trip Detail: Cover image ขนาดใหญ่ + Overlay back/favorite buttons
• Compatibility Score แสดง prominent ด้วยสีเขียว พร้อมรายละเอียดว่าเข้ากันเรื่องอะไรบ้าง
• Host card แสดง Trust Score + Badge + Rating — กดเพื่อดูโปรไฟล์เต็ม
• Join button = Fixed bottom CTA + ปุ่มแชทข้างๆ
• Create Trip ใช้ Multi-step form (2 ขั้น) — ลด cognitive load
• ประเภททริปเลือกด้วย tag chips (multi-select)

W09 — Host Dashboard
Approve/Reject + Members + Stats
📋 Design Notes — My Trips & Host Dashboard • My Trips: แยก tabs "ที่ฉันสร้าง" vs "ที่ฉันเข้าร่วม" — color-coded border ตาม status
• Host Dashboard: แสดง stats ด้านบน (สมาชิก, รออนุมัติ, ว่างอีก)
• คำขอเข้าร่วม: แสดง Trust Score + Compatibility % ช่วย Host ตัดสินใจ
• ปุ่ม Approve/Reject ชัดเจน สีเขียว/แดง + ดูโปรไฟล์ก่อนอนุมัติ
• Anonymous Matching: Host เห็นแค่ Trust Score / Compatibility / Badge — ไม่เห็นข้อมูลส่วนตัว จนกว่าจะ Approve

W11 — Trip Chat
Messages + รูป + Location + Send
📋 Design Notes — Chat • Chat List: แสดงเฉพาะทริปที่ Approved — ไฮไลท์ห้องที่มี unread (สีฟ้าอ่อน + badge จำนวน)
• Trip Chat: Group chat ตาม trip — แสดง avatar + ชื่อ + timestamp
• รองรับ: ข้อความ, รูป, แชร์ Location — ใช้ Supabase Realtime
• ข้อความของตัวเอง = สีน้ำเงิน ชิดขวา / ของคนอื่น = สีขาว ชิดซ้าย
• ด้านบนแสดงจำนวนสมาชิก กดเพื่อดูรายชื่อ

W13 — User Profile (Public)
Trust Passport + Reviews + Block/Report
📋 Design Notes — Profile • My Profile: Trust Passport เป็น hero card — แสดง Trust Score, Stats, Badges

W15 — Notifications
Grouped by date + Color-coded icons
